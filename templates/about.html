About This Project

Heart Disease Risk Prediction Using Clinical and Lifestyle Data

📄 Project Synopsis

Heart disease remains a leading cause of global mortality, accounting for approximately 17.9 million deaths annually according to the World Health Organization. Early detection is crucial for reducing death rates and enabling timely medical interventions.

This project develops an efficient heart disease prediction system using various machine learning algorithms on publicly available datasets — primarily the Cleveland Heart Disease dataset from the UCI Machine Learning Repository (303 patient records, 14 medical attributes).

Multiple supervised ML algorithms are implemented and evaluated including Logistic Regression, KNN, SVM, Decision Tree, Random Forest, XGBoost, and ANN.
